### ☀️ Solar Design Studio

> **Solar EPC Site Design & Engineering Platform**

A web-based engineering tool for **solar site assessment and preliminary PV system design**, combining satellite mapping, site boundary measurement, obstacle mapping, and engineering-oriented visualization.

🌐 **Live Demo:** [Solar Design Studio](https://solar-designed-map.web.app/)
